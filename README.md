# MongoDB Aggregation Mastery

A practical learning repository documenting my journey with MongoDB aggregation, from fundamental pipeline stages to advanced data analysis and real-world backend applications.

## Topics Covered

* `$match` — Filter documents
* `$group` — Group documents and calculate summaries
* `$sum` — Calculate totals and count documents
* `$avg` — Calculate averages
* `$sort` — Sort aggregation results
* `$gte` — Filter using comparison operators

## Practice Dataset

The initial exercises use an employee task management dataset containing:

* Task title
* Employee name
* Task status
* Task priority
* Working hours

## Learning Approach

Each topic includes practical examples, expected results, and exercises designed to build a deeper understanding of MongoDB aggregation pipelines.
